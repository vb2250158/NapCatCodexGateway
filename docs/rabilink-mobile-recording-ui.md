# Rabi 移动端：记录、消息与设备

[English](rabilink-mobile-recording-ui_en.md) | 简体中文

0.3.22 精简包开始采用四页导航：首页、记录、消息、设备。首次打开进入首页，不要求先连接电脑。采集状态由服务持有，切页和熄屏不等于停止录制。

## 日常使用

1. 在首页点按或拖动三档滑条，选择“暂停 / 录音 / 视频录像”。选择模式不会自动开始采集。
2. 录音可选择手机或眼镜麦克风，点击底部“开始录音”；首次按系统提示授权。手机录音无需互联网，眼镜录音仍需已授权的 CXR-L 与蓝牙连接。
3. 视频模式提供动态预览、全屏、开播步骤及底部接收按钮。视频包含声音；实时预览静音，保存与回看保留原声音。
4. 切到暂停，或在首页、消息页、通知栏点“停止并保存”。切换采集模式先停止旧采集，保存与释放完成前不开始新采集。
5. 在“记录”查看本地录音、录像及已经接收的转写。一次新录像对应一条记录，内部分钟分段按顺序连续回放；分享时明确导出原始分段，不假装已合并成一个文件。
6. “消息”保留现有聊天、草稿、未读和人格入口。“设备”提供眼镜授权、音视频状态、电脑连接、健康设备和高级设置入口。

本地录音保存为 16 kHz 单声道 WAV。当前本地录像和新本地录音不会自动提交转写，不显示虚假的“等待联网转写”。已有会话语音处理仍在高级设置中保留，已有转写从原聊天记录读取，不改写历史归属。

## 状态和兼容边界

- 开始接收不等于眼镜已经开播；收到视频后才显示录像计时和实时画面。
- 自有眼镜应用自动开播仍在安装验收阶段，默认关闭，放在开播步骤的实验入口。原生乐奇直播保留为已验证的兼容路线，不使用 CXR-M。
- 手动乐奇直播由乐奇控制。Rabi 的暂停会停止手机接收和保存；需要彻底关闭眼镜原生相机时，仍须在乐奇结束直播。
- 眼镜“已授权”不等于声音或视频已连接。设备页分别显示当前接收证据，没有证据时明确未验证。
- 无旧会话清单的历史视频保留为可展开的原始分段，不根据相近时间猜测合并。升级不删除旧文件。
- 旧录像 Activity 仅保留通知与旧 Intent 跳转，日常界面统一到新首页。旧持续会话设置暂留高级区，以保留已经存在的 PC 语音处理能力；待本地录音的可靠提交、转写归属与恢复验收完成后，迁移并移除旧采集配置入口。
- 原始录音队列仍由原服务管理，不转换、删除或自动导出旧 PCM 队列；记录页展示新本地录音、旧/新视频和已收到的文字转写。

## 保存与故障

真机跨页面测试暴露了旧会话队列恢复阻塞主线程并触发 ANR 的问题。现将队列初始化放到后台单线程，服务先及时进入前台状态；初始化期间命令有序等待，销毁后不执行迟到命令。恢复失败保留原文件并显示失败，不把恢复过程显示为消息连接成功。

录音使用有界队列和单写线程。WAV 头定期更新，停止时刷新并同步；空间低于 256 MiB 或写入失败时停止，原文件保留并标记中断。强杀或断电仍可能损失未完成的数据，不能等同于正常停止保存。

视频沿用本地 MediaMTX 接收与原音视频分段，新增每次会话清单。预览错误不停止录像；文件分享经 FileProvider 授予所选应用临时读取权限。卸载前请导出需要保留的记录。

## 验证记录

2026-09-08：Android 构建与单元测试通过；采集互斥并发测试和 WAV 长度/内容测试通过。手机完成 80.46 秒录音、后台继续、停止保存与有声回放；最终安装包再次关闭移动数据与 Wi-Fi，完成 49.42 秒录音；从消息页停止保存后，WAV 完整读取通过，随后恢复 Wi-Fi。

本轮局域网测试源连续推流 72 秒，手机预览、切到消息页后继续录像、停止保存及单条会话展示通过；两段 H.264/AAC 文件分别为 60.064 秒和 12.014 秒，完整解码通过。眼镜自动应用安装没有因 UI 改版变成成功；眼镜麦克风与自有眼镜端开播仍须单独验收。更多媒体链路证据见[离线录像](rabilink-offline-recording.md)，SDK 限制见[乐奇开发依据](rokid-development.md)。
